A configurable, superscalar out-of-order processor with TAGE prediction, scalar floating point, and Sv32/Sv39 virtual memory. The default RV64 configuration supports RVA22S64.

From source to simulation.

make setup-rtl

# RV32 · batch mode · no waveform
make run-rv32 ARGS="-b -n"
