Pipeline, queues, and PMA windows

Pipeline holds Frontend and Backend, including UOQ, the MDQ multiplier, and the store queue. Memory holds L1, TLB, PTW, MSHR, PMP, and the device windows. Wires stay in-row or in the gutter. Occupancy illustrates a simplified queue model on CoreMark bytes in listing order. Branches do not redirect; cache replay and RTL completion bypasses are omitted. Displayed model IPC is not a processor performance measurement.
