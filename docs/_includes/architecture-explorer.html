How to read this diagram

Blocks group related RTL functions. Capacities use the default preset; RV32 and RV64 share this organization. A dashed block marks an optional cache stage.

Each view expands one part of the system and groups the other part into a linked overview block. Click its “Open” action, press Enter or Space, or choose it in the block selector to switch views. Playback continues at the same cycle.

Select a block to see its current instructions and emphasize its direct connections. Use Tab and Enter, or the block selector, for keyboard navigation.

Animation scope

Branches do not redirect. Translation, cache contents, replay, register allocation, and store draining are not simulated. Their blocks remain available for inspection.

Dots preview up to five instructions per block; counts include all instructions. Select a block for its current instruction listing.

One instruction can occupy the ROB and an execution unit at the same time. Counts belong to each structure and should not be added together.
